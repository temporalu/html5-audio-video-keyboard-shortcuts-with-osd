This repository contains a forked project from "HTML5 Audio/Video Keyboard Shortcuts With OSD" [publicly available on GreasyFork](https://greasyfork.org/en/scripts/390508-html5-audio-video-keyboard-shortcuts-with-osd). I made some changes to meet my habits.

## Recent changes

- `Z` / `X`: rewind 15 seconds / fast forward 30 seconds.
- `W` / `A` / `R`: set playback speed to 2.4x / 1.5x / 3x.
- `S` / `D`: decrease / increase playback speed by 0.1x.
- `P`: toggle Picture-In-Picture (`ALT+P` still works).
- `L`: on YouTube, set video quality to 1080p; if 1080p is not available, the closest available quality is selected. Other sites are not supported yet.
